<div className="pr-eyebrow">Public Reason Project · OpenReason Protocol</div>

<h1 className="pr-h1">Reasoning you can <span className="accent">verify</span> — by people and machines.</h1>

<p className="pr-lead">
OpenReason is an open standard for documenting the reasoning behind consequential decisions — where the
data came from, what was assumed, who is affected — so any party can inspect it, fork it, and re-run it.
Since v0.3, the same document can be a <strong>cryptographically verifiable data product</strong> an agent
checks and enforces on agent-to-agent rails.
</p>

<div className="pr-copy">
<h2>Not a report. A simulatable object.</h2>
<p className="pr-body">
An ORP document is reasoning you can re-run — five structured layers, from where the data came from to how
the conclusion was reached, that anyone can fork and re-run with different assumptions. Disagreement becomes
<em>locatable</em>: you can point to the exact assumption two parties diverge on.
</p>
<p className="pr-body" style={{ marginTop: '14px' }}>
In v0.3 the object is <strong>sealed with a signature</strong> — so a machine can verify the whole thing
offline and know exactly how far to trust it.
</p>
