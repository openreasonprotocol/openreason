# REST API

HTTP API for validating ORP documents.

## Base URL

```
https://api.publicreasonproject.org
```

## Endpoints

### POST /api/v1/validate

Full schema validation.

### POST /api/v1/check

Quick compliance check.

### POST /api/v1/diff

Compare two documents.

## Rate Limits

60 requests per minute per IP address.
