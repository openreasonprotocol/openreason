## Abstract

Contemporary data governance discourse — spanning algorithmic accountability, fairness-aware machine learning, data protection law, and open data initiatives — proceeds from a shared and largely unexamined assumption: that the data asset is a pre-ethical given whose governance problems emerge downstream of its production. This paper argues that this assumption constitutes the foundational error of contemporary data governance, and that correcting it requires both a different philosophical framework and a different class of procedural instrument than those currently available.

We introduce the **constitutive problem in data**: the systematic encoding of interests, exclusions, and assumptions into data assets prior to any downstream use, through mechanisms including scope capture, publication bias, and exclusion by design, that are structurally incentivized and currently ungoverned by existing frameworks. We demonstrate that data protection law, algorithmic accountability frameworks, and open data initiatives share a common architectural failure — each addresses genuine concerns downstream of data constitution while generating false confidence that adequate epistemic scrutiny has been applied, when the most fundamental layer of that scrutiny is absent.

We then introduce **Rational, Empathy-Informed Ethics (REE)** as the philosophical framework adequate to the constitutive problem. REE reorients ethical responsibility to the moment of data constitution, integrates rational accountability with systematic attention to whose experience is encoded and whose is absent, and is organized around five operationalizable principles: Measured Compassion, Rational Inquiry, Simulated Consequences, Universal Sentience, and Transparent Accountability.

Finally, we present the **OpenReason Protocol (ORP)** as the concrete operationalization of REE's philosophical architecture — a working, publicly available protocol whose five-layer structure maps directly onto REE's five principles and whose graduated compliance levels provide an implementation pathway for institutional adoption. We demonstrate ORP's operation through the case of the 2024 Danish property tax reform, showing how the protocol surfaces constitutive-layer information that no existing governance framework requires to be made visible.

The paper concludes that model-level accountability is insufficient without constitutive-layer accountability, that REE provides the philosophical grounding for the latter, and that ORP provides its procedural form — together constituting not a supplement to existing data governance frameworks but the missing foundation on which adequate governance must rest.

**Keywords:** data governance, epistemic transparency, data provenance, algorithmic accountability, information ethics, constitutive problem, REE, OpenReason Protocol
